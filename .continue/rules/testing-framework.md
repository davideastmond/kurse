---
description: Testing Framework
---

- Do not use jest or enzyme for tests. Do not import from jest or enzyme.
- Use Vitest assertions and testing-library for tests.
- Use Vitest for unit tests and integration tests and mocking.
- This code base uses TypeScript. Do not write JavaScript files. All files must be `.ts` or `.tsx`.
- Re-run your output so import errors are resolved. If you see an import error, re-run your output and the error should be resolved.
